# Site Coca - Cloud Storage

Este projeto foi desenvolvido pelo aluno Carlos Eduardo Braga da turma MIDS 77 como parte da atividade da UC de Programação Front-End do curso de Desenvolvimento de Sistemas do CentroWeg, sob orientação do professor Kristian Erdmann.

## Objetivo

O objetivo desta atividade foi replicar fielmente o design fornecido no Figma usando HTML e CSS, tornando-o responsivo e utilizando Flexbox e Grid para criar layouts modernos e adaptáveis.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries para responsividade

## Características do Projeto

- **Design Fiel**: Replicação precisa do design original do Figma
- **Responsividade**: Layout adaptável para diferentes tamanhos de tela
- **Flexbox e Grid**: Uso de layouts modernos para melhor organização
- **Variáveis CSS**: Sistema de design consistente com variáveis CSS
- **Media Queries**: Breakpoints otimizados para diferentes dispositivos

## Estrutura do Projeto

```
site-figma-terminar/
├── index.html          # Página principal
├── styles/
│   └── style.css       # Estilos CSS
├── assets/
│   ├── images/         # Imagens do projeto
│   └── fonts/          # Fontes personalizadas
└── README.md           # Este arquivo
```

## Responsividade

O projeto foi desenvolvido com foco na responsividade, incluindo:

- Layout mobile-first
- Media queries para tablets e desktops
- Uso de unidades relativas (rem, em, vw, vh)
- Grid e Flexbox para layouts adaptáveis
- Imagens responsivas

## Como Executar

1. Clone ou baixe o projeto
2. Abra o arquivo `index.html` em um navegador web
3. Teste a responsividade redimensionando a janela do navegador
