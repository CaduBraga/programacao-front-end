## Descrição do Projeto
Este é um site desenvolvido para a empresa fictícia "Coca", especializada em soluções de armazenamento em nuvem. O projeto apresenta uma interface moderna e responsiva que destaca os principais recursos da plataforma, incluindo colaboração em tempo real, compartilhamento de arquivos sob demanda e opções flexíveis de armazenamento (nuvem, local ou híbrido).

O site foi desenvolvido com foco na acessibilidade, incluindo descrições detalhadas para todas as imagens, garantindo uma experiência inclusiva para todos os usuários.

## Como Executar Localmente

1. **Clone ou baixe o projeto** para sua máquina local
2. **Navegue até a pasta** `site-figma`
3. **Abra o arquivo** `index.html` em seu navegador preferido

### Alternativa usando servidor local:
Se você tiver Python instalado:
```bash
cd site-figma
python -m http.server 8000
```
Depois acesse `http://localhost:8000` no seu navegador.
