# Programação Front-End

Este repositório contém todas as atividades realizadas na Unidade Curricular de **Programação Front-End**, ministrada pelo professor **Kristian Erdmann** na turma **MIDS 77** do **CentroWeg**.

## 📚 Sobre a Disciplina

A disciplina de Programação Front-End aborda os fundamentos e práticas modernas de desenvolvimento web, focando em HTML, CSS e JavaScript para criar interfaces responsivas e interativas.

## 🎯 Projetos Desenvolvidos

### 1. **Primeira Aula** (`primeira-aula/`)
- Introdução aos conceitos básicos de HTML e CSS
- Primeiros passos na estruturação de páginas web

### 2. **About Me** (`about-me/`)
- Página pessoal desenvolvida com HTML e CSS
- Apresentação pessoal com seções organizadas
- Navegação entre diferentes páginas de conteúdo
- Início da aprendizagem, site de tema livre para trabalhar o uso de HTML e CSS

### 3. **Café Aurora** (`cafe-aurora/`)
- Site para uma cafeteria fictícia
- Design responsivo e moderno
- Apresentação de produtos e horários de funcionamento

### 4. **Jardim Botânico** (`jardim-botanico/`)
- Site institucional para um jardim botânico
- Categorização de plantas (medicinais e ornamentais)
- Layout organizado com imagens e informações

### 5. **Site Viagens** (`site-viagens/`)
- Plataforma de destinos turísticos
- Apresentação de diferentes cidades
- Design focado em experiências de viagem
- Primeiro contato com CSS

### 6. **Site Figma** (`site-figma/`)
- Recriação de design do Figma
- Múltiplas páginas com navegação completa
- Foco em freelancers e oportunidades de trabalho

### 7. **Sabores da Ciência** (`sabores-da-ciencia/`)
- **Projeto Principal** - Restaurante temático
- Menu completo com pratos inspirados em cientistas
- Com base em um site de referência passado pelo professor
- Páginas individuais para cada prato
- Design profissional com paleta de cores consistente

### 8. **Talent Hive** (`talent-hive/`)
- Plataforma de talentos e oportunidades
- Interface moderna para conexão profissional
- Réplica de um modelo do Figma entregue pelo professor

### 9. **Site Figma** (`site-figma/`)
- Versão finalizada do projeto Figma
- Criação do site a partir do protótipo de alta fidelidade do Figma
- **Melhorias de Acessibilidade**: Implementação de atributos `alt` descritivos para todas as imagens
- Foco em experiência inclusiva e conformidade com padrões WCAG

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estruturação de conteúdo
- **CSS3** - Estilização e layout
  - Flexbox para layouts responsivos
  - Transformações e animações
  - Paletas de cores consistentes
- **Acessibilidade Web** - Implementação de boas práticas
  - Atributos `alt` descritivos
  - Conformidade com padrões WCAG
  - Experiência inclusiva para todos os usuários
